# LeNet Architecture

## Overview

LeNet is a foundational convolutional neural network (CNN) architecture proposed for handwritten digit recognition. This repository contains Jupyter Notebook implementations and experiments based on the LeNet architecture.

## Features

- LeNet-style convolutional neural network implementation
- Jupyter Notebook-based workflow
- Image preprocessing and model experimentation
- Model training and evaluation

## Repository Structure

```text
LeNet_Architecture/
├── README.md
└── .ipynb files
```

## Getting Started

### Prerequisites

Install Python and Jupyter Notebook.

```bash
pip install jupyter
```

### Installation

Clone the repository:

```bash
git clone https://github.com/sakthiiiiiiii/LeNet_Architecture.git
cd LeNet_Architecture
```

Launch Jupyter:

```bash
jupyter notebook
```

Open the relevant `.ipynb` notebook and run the cells in order.

## Usage

The notebooks demonstrate:

1. Loading or preparing image data
2. Preprocessing and normalization
3. Defining a LeNet-style CNN
4. Training the model
5. Evaluating model performance
6. Visualizing predictions or training results
